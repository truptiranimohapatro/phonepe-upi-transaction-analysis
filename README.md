# PhonePe Transactions Analysis Dashboard using Excel

## Project Overview
This project analyzes PhonePe transaction data using Microsoft Excel to understand transaction trends, payment performance, and user transaction behavior through an interactive dashboard.

## Tools & Technologies
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Data cleaning and analysis
- Dashboard visualization

## Project Objectives
- Analyze transaction amounts and transaction volumes.
- Identify trends and patterns in the available data.
- Present key performance indicators (KPIs).
- Create an interactive dashboard for data-driven insights.

## Repository Structure
- `data/` – Raw or cleaned dataset
- `dashboard/` – Excel dashboard workbook
- `images/` – Dashboard screenshots and project visuals
