# PhonePe UPI Transaction Analysis Dashboard

An interactive PhonePe UPI transaction analysis dashboard built using Microsoft Excel to explore transaction trends and visualize key insights.

## Tools & Technologies
- Microsoft Excel
- PivotTables and PivotCharts
- Data Analysis
- Dashboard Design and Data Visualization
